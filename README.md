# 🌍 Global Seismic Trends and Patterns

## 📌 Project Overview

**Global Seismic Trends and Patterns** is a Data Science project that analyzes earthquake activity across the world using data collected from the **USGS Earthquake API**.

The project focuses on collecting earthquake data from the past five years, cleaning and transforming the data using Python and Pandas, storing the processed data in MySQL, and performing SQL-based analysis to identify important seismic patterns and trends.

The final results can be presented through a **Streamlit dashboard** for easier visualization and exploration.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Collect earthquake data from the USGS Earthquake API.
- Analyze global earthquake activity over the past five years.
- Clean and transform raw earthquake data.
- Handle missing and inconsistent values.
- Extract useful information from earthquake location data.
- Create derived columns for deeper analysis.
- Store the cleaned dataset in MySQL.
- Perform analytical queries using SQL.
- Identify important earthquake trends and patterns.
- Present the results through a Streamlit application.
